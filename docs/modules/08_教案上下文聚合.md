# 08. 教案上下文聚合

**文件**: `app/service/lesson_context.py`

## 职责概述

将多源数据聚合为 `LessonContext`，为 Orchestrator 提供统一的生成上下文。

## 上下文组成

```python
class LessonContext:
    clarify: LessonClarifySchema        # 澄清数据（必需）
    student_profile: Optional[Dict]       # 学情档案
    rag_context: Optional[Dict]         # RAG 检索结果（预留）
    kg_context: Optional[Dict]          # 知识图谱结果（预留）
```

## 核心函数

### build_lesson_context(db, teacher_id, clarify, include_student_profile)

主入口，聚合所有上下文数据。

### _filter_relevant_profiles(profiles_data, subject, grade)

按学科/年级过滤相关学情档案。

### format_student_profile_for_prompt(student_profile)

将学情档案格式化为 Prompt 友好格式。

### format_partial_lesson_for_prompt(partial_lesson)

将已生成内容格式化为 Prompt 友好格式（限制长度，避免超出 LLM 上下文）。

## 数据流

```
build_lesson_context()
    │
    ├─→ clarify (直接传入)
    │
    └─→ student_profile
            │
            └─→ build_learning_profiles_set(db, teacher_id)
                    │
                    └─→ _filter_relevant_profiles(..., subject, grade)
```

## 预留扩展

```python
rag_context=None  # 未来可接入教材 RAG 知识库
```
