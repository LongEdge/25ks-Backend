# 02. 教案生成编排器

**文件**: `app/ai/langchain/orchestrator/lesson_orchestrator.py` (274 行)

## 职责概述

`LessonOrchestrator` 是教案生成的核心编排器，负责：
1. 按 pipeline 顺序逐章节调用 LLM 生成教案内容
2. 管理 Redis 任务状态（进度、部分结果）
3. 生成完成后将教案落库 MySQL

## 核心流程

```
生成触发 (POST /api/v1/ai/lesson/generate)
    │
    ├─→ init_lesson_task()        # Redis 初始化任务
    ├─→ build_lesson_context()    # 构建上下文（含学情）
    ├─→ create_orchestrator()     # 创建编排器实例
    └─→ background_tasks.add_task(orchestrator.run_pipeline_sync)
            │
            ├─→ for stage in GENERATION_PIPELINE:
            │       ├─→ 检查是否被锁定 (locked_sections)
            │       ├─→ update_lesson_task(progress)
            │       ├─→ _generate_section(stage)
            │       └─→ update_partial_lesson(task_id, stage, content)
            │
            └─→ _save_to_mysql()  # 落库
                └─→ mark_task_completed()
```

## 生成 Pipeline

```python
GENERATION_PIPELINE = [
    "objectives",                    # 教学目标
    "key_points",                   # 教学重难点
    "teaching_flow.introduction",   # 导入新课
    "teaching_flow.main",           # 新授环节
    "teaching_flow.practice",       # 课堂练习
    "teaching_flow.summary",        # 课堂小结
    "homework",                     # 作业布置
    "board_design",                 # 板书设计
    "remarks",                      # 教学反思
]
```

共 9 个阶段，进度按 `(i+1)/total_stages` 计算。

## 章节锁定机制

```python
# 已锁定的章节（如用户手动编辑过）不会重新生成
locked_sections = task.get("locked_sections", [])
if stage in locked_sections:
    continue  # 跳过
```

```python
response = self.llm.invoke(messages)
```

## Prompt 构建

每个章节的 Prompt 由 `get_section_prompt(stage)` 从 `prompts/LESSON.py` 获取，包含：
- 学科、年级、课题等基本信息
- 当前学情 profile
- 已生成的章节内容（partial_lesson）

## 异常处理

```python
except Exception as e:
```

## TTL 管理

- 任务 TTL 初始 1 小时
- 每 3 个阶段延长 1 小时：`extend_task_ttl(self.task_id, 3600)`
- 防止长时间生成导致 Redis key 过期
