# 04. 教案澄清会话

**文件**: `app/ai/langchain/utils/lesson_session.py`

## 职责概述

管理教案生成的澄清（Clarify）多轮对话会话，通过对话收集生成所需的 4 个核心字段：
- `subject`（学科）
- `grade`（年级）
- `lesson_title`（课题名称）
- `lesson_type`（课程类型）

## 对话阶段流转

```
stage: "collecting_subject" → "collecting_grade" → "collecting_title" → "collecting_type" → "confirmed"
```

## 核心 API

### lesson_clarify_chat(session_id, message)

处理用户消息，返回 AI 回复和当前状态。

### get_lesson_clarify_state(session_id)

获取会话状态。

### confirm_lesson_clarify(session_id, confirm_md)

确认信息并提供最终确认文本。

### reset_lesson_session(session_id)

重置会话。

## 数据结构

```python
class LessonClarifyState:
    session_id: str
    stage: str  # 收集阶段
    history: List[Dict]  # 对话历史
    clarify: LessonClarifySchema  # 已收集的信息
    confirm_md: str  # 待确认的说明文本
```

## 前端集成流程

```
1. 前端创建 session_id (uuid)
2. POST /ai/lesson/clarify/chat {session_id, message}
3. 渲染 AI 回复，引导用户补充信息
4. 循环直到 is_complete=true
5. POST /ai/lesson/generate {session_id, confirm_md_final}
```
