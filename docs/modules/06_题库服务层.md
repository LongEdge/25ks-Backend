# 06. 题库服务层

**文件**: `app/service/exercise_service.py`

## 职责概述

封装题库的 CRUD 操作，提供数据库层面的持久化支持。

## 核心接口

### save_exercise_set(db, exercise_set, teacher_id)

将生成的题库保存到数据库。

### get_exercise_list(db, teacher_id, page, page_size, subject, difficulty)

分页查询题库列表。

### get_exercise_by_id(db, exercise_id, teacher_id)

获取题库详情（带权限检查）。

### update_exercise(db, exercise_id, teacher_id, update_data)

更新题库信息或题目内容。

### delete_exercise(db, exercise_id, teacher_id)

软删除题库（设置 is_deleted=True）。

## 数据模型

题库存储在 `exercise_sets` 表，每条记录包含：
- `exercise_set_id`：全局唯一标识
- `teacher_id`：所属教师
- `title`：题库标题
- `subject`：学科
- `overall_difficulty`：整体难度
- `exercises`：题目列表（JSON 字段）
- `is_deleted`：软删除标记
