# 11. 智谱媒体服务

**文件**: `app/core/zhipu_media.py` (244 行)

## 职责概述

封装智谱 AI 的媒体生成能力，提供：
- **图像生成**：CogView-3 Flash（同步）
- **视频生成**：CogVideoX Flash（异步）
- **提示词优化**：用 GLM-4 优化用户输入

## 图像生成

```python
POST /api/v1/media/image/generate
```

```python
payload = {
    "model": "cogview-3-flash",
    "prompt": prompt,
    "size": "1024x1024",  # 可选 768x1344, 1344x768
    "quality": "standard", # 或 "hd"
    "watermark_enabled": False
}
```

**流程**：
1. 可选：调用 `optimize_prompt()` 用 GLM-4 优化提示词
2. 调用智谱 `/images/generations` 接口
3. 返回图像 URL 和创建时间

## 视频生成（异步）

```python
POST /api/v1/media/video/generate
```

```python
payload = {
    "model": "cogvideox-flash",
    "prompt": prompt,
    "size": "1024x1024",
    "fps": 30,
    "quality": "speed",  # 或 "quality"
    "with_audio": True,
    "watermark_enabled": False
}
```

**状态查询**：
```python
GET /api/v1/media/video/status/{task_id}
```

任务状态：`PROCESSING` → `SUCCESS` / `FAIL`

## 前端集成示例

```javascript
// 生成图像
const res = await fetch('/api/v1/media/image/generate', {
  method: 'POST',
  headers: {'Authorization': 'Bearer ' + token},
  body: JSON.stringify({
    prompt: '老师讲解二次函数',
    optimize_prompt: true
  })
});
const { image_url } = await res.json();

// 生成视频（轮询）
const videoRes = await fetch('/api/v1/media/video/generate', {...});
const { task_id } = await videoRes.json();

// 轮询状态
let status;
while (status !== 'SUCCESS' && status !== 'FAIL') {
  await sleep(3000);
  const result = await fetch(`/api/v1/media/video/status/${task_id}`);
  const data = await result.json();
  status = data.task_status;
  if (status === 'SUCCESS') {
    console.log(data.video_url);
  }
}
```
