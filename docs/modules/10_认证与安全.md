**文件**: `app/core/security.py` + `app/api/v1/auth.py`

## 认证架构

### 密码处理

```python
pwd_context = CryptContext(schemes=["argon2"], deprecated="auto")

# 注册时
hashed_password = get_password_hash(password)  # Argon2 哈希

# 登录时
verify_password(plain_password, hashed_password)  # 验证
```

> Argon2 是目前最推荐的密码哈希算法，比 bcrypt 更安全。

### JWT Token

```python
# 创建 Token
access_token = create_access_token(data={"sub": str(user.id)})

# 解码 Token
payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])

# 获取当前用户
user_id = payload.get("sub")
user = db.query(User).filter(User.id == int(user_id)).first()
```

### Token 过期

```python
ACCESS_TOKEN_EXPIRE_MINUTES = 30  # 默认 30 分钟
expire = datetime.utcnow() + timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
```

## Auth API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/auth/register` | POST | 注册（用户名/邮箱唯一性检查） |
| `/api/v1/auth/login` | POST | 登录（OAuth2PasswordRequestForm） |
| `/api/v1/auth/logout` | POST | 登出（JWT 无状态，客户端删除 token） |
| `/api/v1/auth/refresh` | POST | 刷新 Token |
| `/api/v1/auth/profile` | GET/PUT | 查看/更新个人信息 |
| `/api/v1/auth/password` | PUT | 修改密码（验证旧密码） |
| `/api/v1/auth/avatar` | POST | 上传头像（Base64 存储） |

## 头像存储

```python
# 读取文件并转为 Base64
contents = await file.read()
base64_content = base64.b64encode(contents).decode('utf-8')
avatar_base64 = f"data:{file.content_type};base64,{base64_content}"

# 存储在 User.avatar_base64 字段
current_user.avatar_base64 = avatar_base64
```

支持格式：`image/jpeg`, `image/png`, `image/gif`, `image/webp`
最大文件大小：5MB
