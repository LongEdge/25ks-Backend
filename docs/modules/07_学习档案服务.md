# 07. 学习档案服务

**文件**: `app/service/learning_profile.py` + `app/ai/langchain/agents/LearnAnalysisAgent.py`

## 职责概述

管理班级/学生的学情档案，支持：
- 创建、更新、查询学习档案
- AI 分析学情，生成教学建议
- 为教案生成提供学情上下文

## 数据结构

```python
LearningProfile:
  scope:
    subject: str      # 学科
    grade: str        # 年级
    related_chapter: str  # 相关章节
  student_data: Dict  # 学生数据（成绩、答题记录等）
  analysis:
    overall_level: str  # 整体水平
    main_issues: List[str]  # 主要问题
    teaching_suggestions: str  # 教学建议
  recommendations: List[str]  # 推荐教学策略
```

## API 路由

- `POST /api/v1/learning_profile` — 创建档案
- `GET /api/v1/learning_profile` — 列表
- `GET /api/v1/learning_profile/{id}` — 详情
- `PUT /api/v1/learning_profile/{id}` — 更新
- `DELETE /api/v1/learning_profile/{id}` — 删除

## AI 分析 Agent

`LearnAnalysisAgent` 负责：
1. 分析学生答题数据
2. 识别知识点薄弱点
3. 生成个性化教学建议
4. 输出结构化 LearningProfile
